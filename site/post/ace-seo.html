새로 만든 홈페이지, 검색에 잡히게 만들기 — 자이에이스 부동산 사이트 SEO 1차 작업 기록

2026. 10. 22·자이에이스 부동산 · ace.hongzi.us

들어가며

사이트를 새로 만들었다고 끝이 아니다. 네이버·구글 검색에 잡히지 않으면 없는 사이트나 마찬가지다. 오늘 와이프가 운영하는 자이에이스 부동산(용인 수지 동천동) 홈페이지 ace.hongzi.us를 리뉴얼한 김에, 검색 노출을 위한 기본 세팅을 한 번에 진행했다. 순수 정적 HTML 사이트 기준으로 정리한다.

1. 검색 결과에 보이는 얼굴부터 — 메타 태그

가장 먼저 손댄 건 페이지 제목과 설명이다.

  • 제목: “자이에이스 부동산 | 용인 수지 동천동 부동산 · 동천자이 매매·전세·상가” — 상호만 있던 제목에 실제 검색어 조합(지역 + 업종 + 대표 단지)을 앞에 배치했다.
  • 설명(description): 어떤 부동산인지 한 문장으로. 검색 결과 제목 아래에 그대로 노출되는 문구다.
  • OG 태그 9종 + 대표 이미지(1200×630): 카카오톡이나 문자로 링크를 공유했을 때 미리보기가 깔끔하게 뜨도록.
  • canonical 태그: 이 페이지의 정식 주소가 무엇인지 검색엔진에 명시.

2. 기계가 읽는 자기소개 — 구조화 데이터(JSON-LD)

사람이 읽는 소개글과 별개로, 검색엔진과 AI가 읽는 표준 형식(schema.org의 RealEstateAgent)으로 상호·주소·대표전화·개설등록번호·대표자명을 페이지에 심었다. 동네 부동산 검색에서 “여기가 실제 등록된 중개사무소”라는 걸 검색엔진이 확신하게 만드는 장치다. 좌표는 정확한 값을 확인하지 못해 억지로 넣지 않았다. 틀린 정보는 없는 것보다 나쁘다.

3. 로봇 안내문과 목차 — robots.txt, sitemap.xml

  • robots.txt: 검색 로봇에게 “어디를 읽어도 되는지 + 사이트맵은 여기 있다”고 안내하는 파일.
  • sitemap.xml: 사이트의 페이지 목차. 지금은 메인 1페이지뿐이라 단출하지만, 나중에 중개 이야기 글이 개별 페이지로 늘어나면 그때부터 진가를 발휘한다.

4. 네이버 서치어드바이저 — 도메인을 재사용한 덕

등록하러 들어가 보니, ace.hongzi.us가 이미 등록돼 있었다. 예전에 같은 도메인으로 워드프레스 사이트를 운영하면서 등록해 둔 것이 남아 있었던 것. 도메인을 버리지 않고 재사용하면 이런 자산이 따라온다.

오늘 한 일:

  • 웹 페이지 수집 요청: 메인 페이지를 다시 읽어가라고 요청 (구 사이트 정보를 들고 있던 상태라 필수였다)
  • 사이트맵 제출: 이미 7월에 제출된 기록이 있어 중복 제출이 막혔고, 삭제 후 재등록했다. 여기서 하나 배운 것 — 제출 입력란에는 전체 주소가 아니라 sitemap.xml 파일명만 넣어야 한다. 앞부분 도메인은 칸에 고정돼 있어서 전체 주소를 붙여 넣으면 주소가 겹쳐 오류가 난다.
  • robots.txt 화면에서 수집요청: 네이버가 들고 있던 robots가 옛 워드프레스 시절 것이라 새것으로 다시 읽도록 요청했다.

5. 함정 — 사이트를 갈아엎으면 소유확인이 위험하다

서치어드바이저 소유는 기존 사이트 기준으로 인증된 상태였다. 문제는 새 사이트에는 네이버 소유확인용 메타 태그가 없다는 것. 당장은 인증이 살아 있어 문제가 없지만, 네이버가 재확인을 돌리는 시점에 등록이 떨어질 수 있다. 대응은 단순하다. 목록에 “소유확인 연장” 안내가 뜨면 그때 확인 코드(HTML 태그)를 받아 새 사이트에 심으면 된다. 사이트를 통째로 교체할 계획이라면 이 부분을 체크리스트에 넣어둘 것.

6. 지도(스마트플레이스)를 따로 봐야 하는 이유

검색만큼 중요한 게 네이버 지도다. “동천동 부동산” 같은 검색은 플레이스 결과가 먼저 뜬다. 직접 확인해 보니:

  • “자이에이스공인중개사사무소”로 이미 등록·노출 중, 주소(고기로 89 상가 에이동 102호) 일치
  • 업주 소개글, 대표 키워드, 매장 사진, 영업시간, 안심번호까지 등록된 관리 중인 플레이스였다
  • 단, 홈페이지 링크만 비어 있었다 — 지도에서 관심을 갖고 온 사람이 홈페이지로 넘어올 길이 없는 상태

정리

스마트플레이스 관리에서 홈페이지 항목에 ace.hongzi.us를 연결하는 게 남은 숙제다. 지도 손님이 홈페이지의 중개 이야기까지 보고 오게 되면 신뢰도가 달라진다.

오늘의 체크리스트를 압축하면 이렇다.

  • 1. 제목·설명·OG·canonical 등 메타 세팅
  • 2. 구조화 데이터(JSON-LD)로 업체 정보 명시
  • 3. robots.txt + sitemap.xml 배치
  • 4. 서치어드바이저에서 수집 요청 + 사이트맵 제출
  • 5. 소유확인 상태 점검 (사이트 교체 시 재확인 리스크)
  • 6. 스마트플레이스 등록·정보 확인, 홈페이지 링크 연결

남은 단계

남은 단계는 구글 서치콘솔 등록(소유확인 코드를 받으면 같은 방식으로 삽입)과, 중개 이야기를 개별 페이지로 쌓아 검색 유입을 늘리는 콘텐츠 작업이다. 세팅은 한 번이면 되지만, 결국 순위를 만드는 건 콘텐츠다.
