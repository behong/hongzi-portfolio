카카오톡 체결 메시지 자동 수집 프로젝트

2026. 10. 24·MacroDroid · 핵심 기술 검증 완료

무엇을 만들었나

주식 체결이 이뤄지면 한국투자증권 카카오톡 채널로 체결 안내 메시지가 도착합니다. 체결가·수량·주문번호가 담긴 긴 메시지인데, 이걸 매매일지에 옮겨 적는 일은 번거롭고 빠뜨리기 쉽습니다. 휴대폰이 스스로 체결 메시지를 읽어 개인 서버로 보내 주는 시스템을 갤럭시 S25 울트라와 MacroDroid로 구축한 기록입니다.

핵심 우회 — 알림이 아니라 화면을 읽는다

처음엔 카카오톡 알림 텍스트를 가져오려 했지만 두 가지 벽에 막혔습니다. 알림 내용이 ‘표시 안 함’으로 설정돼 있었고(‘이름 + 메시지’로 변경해 해결), 그보다 근본적으로 긴 체결 메시지는 알림에서 중간에 잘려 주문번호 같은 뒷부분이 누락됐습니다.

그래서 방식을 바꿨습니다. 플로팅 버튼을 누르면 카카오톡이 실행되고, 한국투자증권 채팅방이 자동으로 열리고, MacroDroid의 ‘화면 텍스트 전체 읽기’가 채팅 화면의 원문을 추출해 kakao_screen 딕셔너리에 담고, 이를 HTTP POST로 개인 서버의 테스트 API(/api/macrodroid/test)에 전송합니다. 주문번호까지 전문 전송이 되는 것을 확인했습니다. 도중에 HTTP 413 오류는 Content-Type과 본문 설정을 고쳐 해결했고, Kakao Developers의 ‘나에게 메시지 보내기’ 테스트도 HTTP 200 · result_code: 0으로 확인했습니다.

검증된 것

  • 카카오톡 알림 감지 및 HTTP 전송
  • 긴 체결 메시지 전체 추출 — 화면 텍스트 읽기로 주문번호까지
  • 한국투자증권 채팅방 자동 열기 (UI 자동조작)
  • 플로팅 버튼 kakao_read로 전체 처리 실행
  • 개인 서버 테스트 API의 HTTP POST 수신
  • 카카오 개발자 API 테스트 메시지 발송 (HTTP 200, result_code: 0)

아직 아닌 것

완료와 미완료를 혼동하지 않기 위해, 프로젝트 페이지에서 상태를 셋으로 구분해 표시합니다.

  • 설정 중·검증 필요 — 알림 이중 필터(제목 ‘한국투자증권’ + 본문 ‘체결안내’): 제목 필터는 설정 화면에서 확인, 본문 필터 저장 여부와 실제 체결 알림에서의 무인 자동 실행은 미확인
  • 미구현 — 매매일지 DB 자동 저장
  • 미구현 — 체결 여부 서버 분석, 거래일 검증, 중복 방지, 민감정보 차단
  • 한계 — 잠금·화면 꺼짐 상태에서는 UI 자동조작이 실패할 수 있고, 화면에 표시되지 않은 메시지는 읽을 수 없음

출처 · 바로가기
