AI Video Models · Study Notes

씨댄스급 AI 영상 모델,
우리 채널 기준으로 제대로 비교하기

기준은 하나입니다. 한국인 캐릭터가 한국어로 말하는 감동 상황극을, 매일 자동으로 만들 수 있는가. 씨댄스(Seedance)를 비롯해 2026년 10월 현재 최상위 클라우드 영상 모델 12종을 실사 품질·한국어 대사·캐릭터 일관성·가격·API 자동화 기준으로 정리했습니다.

조사일 2026년 10월 22일 (KST) 용도 55+ 시청자 채널 · 쇼츠 하루 3편(약 90초) + 주 1회 롱폼 10분 주의 이 시장 가격은 매달 바뀝니다 — 모든 가격에 출처를 달았습니다
결론 먼저 한눈에 비교표 비용 계산기 모델별 상세 한국인·노인 얼굴 벤치마크 아직 모르는 것 출처

01결론 먼저

가장 중요한 발견: 한국어 대사와 립싱크를 공식 문서로 명시하는 모델은 다섯 계열뿐입니다 — 씨댄스, 클링 3.0, 미니맥스 H3, 그리고 문서가 약한 Wan 3.0과 Veo 3.1. Runway·Luma·Pika·Hailuo 구버전은 무음이라 지금 겪는 TTS+립싱크 수작업이 그대로 남습니다.

1순위 · 대사 엔진

Kling 3.0 (클링)

한국어 네이티브 대사를 명시한 5개 언어 중 하나. 캐릭터별 목소리 고정, Elements 얼굴 잠금(정면+각도 레퍼런스), 한 번 생성에 최대 6컷 스토리보드(AI Director)까지 — 반복 등장 캐릭터가 필요한 채널에 가장 완성된 조합입니다.

$0.13/초 (Standard+오디오) · 쇼츠 약 $35/일
2순위 · 가성비 엔진

Seedance 1.5 Pro (씨댄스)

한국어 대사가 되는 모델 중 가장 쌉니다. 음성·영상을 한 번에 생성하는 joint AV 방식이라 립싱크가 본업. 히어로 장면은 상위 버전 2.0을 골라 쓰고, 2.5는 비싸서 보류가 낫습니다.

$0.052/초 (fal, 720p+오디오) · 쇼츠 약 $14/일
3순위 · 가치 도전

MiniMax H3

벤치마크 상위권 품질에 한국어 포함 11개 언어 대사를 명시, 스테레오 오디오. 우리 프롬프트로 노인 얼굴 테스트만 통과하면 1순위를 갈아치울 수 있는 가격입니다.

$0.08/초 (768p) · 쇼츠 약 $22/일
추천 파이프라인: 대본 → 캐릭터 스틸 먼저 확정(지금 방식 그대로, 나이·한국인 얼굴을 눈으로 검수) → 대사 장면은 Kling 3.0 또는 Seedance 1.5 Pro → B-roll·롱폼 연결 장면은 Wan 3.0 / H3 → 자막·내레이션은 기존 방식 유지. 구독 요금제는 이 물량(월 약 8,100초 생성)을 못 버티므로 종량제 API가 정직한 예산입니다.
그리고 하나 더: OpenAI Sora 2는 종료됐습니다 (API 2026년 9월 24일 중단). 아직 떠도는 "Sora" 애그리게이터 상품에 새 파이프라인을 얹으면 안 됩니다.

03비용 계산기 — 하루 제작비가 실제로 얼마인가

리서치의 비용 모델 그대로입니다. 완성 1초를 얻으려면 평균 3번 생성한다고 가정하고, 쇼츠는 720p급 + 오디오 등급으로 계산합니다. 슬라이더를 움직이면 우리 채널 물량에 맞춰 다시 계산됩니다. 무음 모델은 TTS·립싱크 비용이 별도입니다.

현재 채널: 25~35초 × 3편 ≈ 90초
얼굴·대사가 어긋나면 버리고 다시 뽑는 횟수
10분 = 600초, 주 1회 제작 가정
한국어 대사 문서 명시 한국어 대사 미보장·미문서 무음 (외부 음성 별도)

막대는 0부터 시작합니다. Luma Ray3.2(720p 약 $0.06–0.09/초, 하루 약 $16–24)와 Pika 2.5(초당 단가 확인 불가)는 범위·불확실성 때문에 계산기에서 제외하고 비교표에만 남겼습니다.

04모델별 상세

각 모델을 같은 7개 항목(실사 · 대사 · 스펙 · 일관성 · 가격 · API · 상업조건)으로 봤습니다. 대사 항목에서 한국어 지원을 함께 평가합니다. 필터로 골라 보세요.

BYTEDANCE

Seedance 1.5 Pro

한국어 명시
실사
상위권. 상위 버전 2.0은 Artificial Analysis 텍스트-투-비디오 스냅샷 1위(Elo 1212)를 기록했습니다.
대사
이 모델의 존재 이유. 음성·영상 동시 생성(joint AV), 밀리초 단위 립싱크, 지원 언어에 한국어 명시 (영·중·일·스페인·포르투갈·인도네시아어 등). 2.0은 음소 단위 립싱크 8개+ 언어.
스펙
4~12초, 480p~1080p, 16:9 / 9:16 / 1:1. (1.0 Pro는 무음, 5/10초)
일관성
1.0부터 네이티브 멀티샷 내러티브. 2.0은 이미지 9 + 영상 3 + 음성 3개 레퍼런스, 2.5는 이미지 최대 30개까지 보고됨.
가격
fal 기준 720p+오디오 $0.052/초 (5초 $0.26). 오디오를 켜면 무음 대비 약 2배. 2.0 직결 약 $0.15/초(720p), 2.5 약 $0.231/초 — 경로에 따라 2~7배 차이가 납니다.
API
BytePlus ModelArk 공식 API + fal/Replicate 등. 크론 자동화 가능.
상업조건
BytePlus API는 워터마크 토글(끔 가능). Dreamina 무료는 워터마크, 유료는 제거+상업 이용.
주의: 일부 호스트는 실존 인물 사진 레퍼런스를 본인인증 없이 거부합니다. 우리처럼 AI로 만든 가상 캐릭터는 해당 없음. BytePlus 직결 계정의 한국 가입 가능 여부는 미확인 — 애그리게이터 경유가 무난합니다.
KUAISHOU

Kling 3.0

한국어 명시
실사
"실사 인물 특화"라는 평가가 반복됩니다. 조명·포토리얼리즘은 Veo에 한 끗 아래, 움직임·물리·가격은 위. 얼굴이 컷을 넘어 유지되는 힘이 강점.
대사
네이티브 오디오 정확히 5개 언어: 중·영·일·한·스페인어. 캐릭터별 목소리 고정, 여러 인물이 각자 목소리·립싱크 유지, 사투리·코드스위칭 지원.
스펙
3~15초, 네이티브 4K까지, 최대 60fps, 16:9/9:16. 연장하면 약 3분까지 체인.
일관성
AI Director: 15초 생성 안에 최대 6컷, 컷마다 길이·샷 크기·카메라 지정. Elements: 정면 + 최대 4개 각도 레퍼런스로 얼굴 잠금 — 반복 캐릭터에 가장 강한 시스템. 최대 3인 주체 일관성.
가격
API: Standard 720p 무음 $0.084 / 오디오 $0.13/초, Pro 1080p 오디오 $0.168~0.17/초, 4K $0.43/초. 구독(Ultra $159.99, 26,000크레딧)으로도 월 필요량의 4분의 1 수준 — 구독은 테스트용, 본편은 종량제.
API
공식 API + fal/Replicate/Runway Dev 등. 글로벌 사이트가 국제용 제품, 한국 제한 없음.
상업조건
무료는 워터마크+비상업+720p 상한. 유료 전 등급 워터마크 제거 + 상업 이용.
주의: Kling 4.0(9월 30일 발표, 최대 30초·스테레오)은 상위 구독자 얼리 액세스만 진행 중 — 아직 파이프라인에 얹을 단계가 아닙니다.
MINIMAX

MiniMax H3 (Hailuo 3.0)

한국어 명시
실사
전작 Hailuo 02는 출시 당시 AA 2위(물리 표현 유명). H3/H3 Max는 2026년 10월 오디오 포함 보드 상위권 (H3 768p 1,138 / H3 Max 1,134).
대사
32kHz 스테레오 네이티브 오디오, 한국어 포함 11개 언어 안정 지원 명시. 레퍼런스 녹음으로 목소리 전이(voice transfer)도 가능.
스펙
4~15초, 24fps, 768p 기본 / 재생성으로 2K, 21:9~9:16.
일관성
옴니 레퍼런스: 이미지 9 + 영상 3 + 음성 3 (12개 파일), 첫/끝 프레임, 멀티샷 생성, 문장 단위 대사 편집.
가격
공식 종량제 768p $0.08/초, 2K $0.13/초. 레퍼런스 음성 무료, 레퍼런스 이미지 5장까지 무료 후 장당 $0.04. 단, MiniMax 직결 API는 월 $1,000+ 단위 패키지 판매 보고가 있어 애그리게이터 진입이 합리적.
API
공식 플랫폼(글로벌) + fal/Replicate/Runway Dev/WaveSpeed.
상업조건
유료 API/구독 출력물 상업 이용 가능, 무료는 워터마크.
주의: H3 오픈 웨이트 라이선스의 지역 제외 조항이 논란 중이라 한국 포함 여부가 미확인입니다. 호스팅 API 경로는 영향 없는 것으로 보이나, 셀프호스팅은 이 문제가 정리될 때까지 보류하세요.
ALIBABA

Wan 3.0

한국어 미검증
실사
재구축된 AA 오디오 포함 보드 1위(Elo 1,156), 무음 보드도 1위(1,129). 단 상위 5개가 오차 ±10 안팎의 20점 차 접전. 통제 테스트 6개 과제에서 Veo 3.1의 4분의 1 가격에 공동 최고 납품 기록, 다른 비교에선 Seedance 2.5가 "연기와 마무리"에서 우세.
대사
오디오(대사·음악·효과음)가 기본으로 한 번에 생성되고 다국어 대사를 주장하지만, 알리바바가 언어 목록을 공개하지 않아 한국어가 명시돼 있지 않습니다. 초기 테스터들은 중·영 외 언어(일본어 지적)를 약점으로 꼽음.
스펙
한 번에 2~30초 — 씨댄스 2.5와 함께 최장. 480p/720p/1080p (4K 없음).
일관성
옴니 레퍼런스: 이미지 10 + 영상 5 + 음성 5, 얼굴·머리·의상·소품·공간 관계까지 긴 클립에서 유지 주장. 약 6장면 넘으면 멀티샷 변형이 무너진다는 테스터 보고 1건.
가격
공식: 480p $0.05 / 720p $0.10 / 1080p $0.20/초 (30초 1080p 1테이크 = $6.00). Runway Dev 요금과 정확히 일치함을 실측 확인.
API

05한국인·노인 얼굴 — 솔직한 현실

먼저 못 박아둡니다: 어떤 모델도 한국인 얼굴, 노인 얼굴, 그 교집합에 대한 공개 벤치마크를 내놓지 않았습니다. 제조사도 벤치마크 기관도 인구통계별 점수를 공개하지 않아요. 아래는 일반 편향 연구와 리뷰 합의로 확인되는 범위입니다.

  • 나이 하향이 기본값입니다. 생성 AI의 노인 묘사는 타 인종보다 백인이 5배 많고, 중립 프롬프트에서도 부정·무표정으로 기운다는 종단 연구가 있습니다 ("디지털 연령차별"). 동아시아 여성 연구에서는 서구화된 이목구비, 젊음 기본값 렌더링, 중·노년 여성을 아름답게 그리는 데의 어려움, 동아시아 국가 간 문화 기호 혼합이 목록화됐습니다.
  • 텍스트만으로 뽑으면 모든 모델이 (a) 나이를 실제보다 젊게 만들고 (b) 한국인 얼굴을 뭉뚱그려진/서구화된 동아시아 얼굴로 흘려보낼 것으로 예상해야 합니다.
  • 그래서 해법은 지금 방식 그대로입니다 — 레퍼런스 우선 제작. 60대 한국인 캐릭터를 스틸로 먼저 만들어 눈으로 검수·확정하고, 그 이미지를 레퍼런스로 영상을 돌리는 것. 모델별 레퍼런스 지원 순위: Seedance 2.0/2.5(이미지 9~30개+영상·음성) ≈ MiniMax H3(이미지 9+음성) ≈ Kling 3.0 Elements(다각도 얼굴 잠금 — 고개 돌림·가림에 최강) > Wan 3.0(이미지 10) > Veo 3.1(3장, Lite 없음) > Runway Gen-4(입력 이미지 1장) > Luma Ray3.14(레퍼런스 자체가 없음).
  • 순수 얼굴 품질에 대한 리뷰 합의: 단일 샷 포토리얼리즘은 Veo 3.1, 컷을 넘어 얼굴이 유지되는 "실사 인물픽"은 Kling 3.0, 블라인드 선호 보드 최상위권에 Seedance 2.x. 중국 랩 모델들(Seedance/Kling/H3/Wan)은 동아시아 영상 학습량이 압도적으로 많고, 공교롭게도 한국어 발화를 문서화한 모델들이기도 해서 대사 장면의 입·얼굴 움직임과도 상관관계가 있습니다.
결정 전 직접 테스트가 답입니다: 같은 프롬프트 20개로 Kling 3.0 vs Seedance 1.5 Pro vs MiniMax H3를 직접 대결(bake-off)시켜 한국인 노인 얼굴과 한국어 대사를 귀로 확인한 뒤 주력을 정하세요. 공개 데이터로는 이 질문에 답할 수 없습니다.

06벤치마크 — 선두는 "무리"로 읽기

Artificial Analysis가 2026년 10월 4일 Video Arena를 재구축(v2.0, 1080p, 68,000표+)하면서 재구축 전후 점수는 비교가 안 됩니다. 아래는 재구축 후 "오디오 포함" 보드 — 상위 5개가 오차범위(±약 10) 안의 약 22점 차 접전입니다. 1등 독주가 아니라 선두 그룹으로 읽어야 합니다.

  • Veo 3.1 한국어 대사 신뢰도 — 구글은 영어만 평가 완료로 문서화. 서드파티의 한국어 음소 지원 주장은 보장되지 않습니다.
